# Приоритизация гипотез и анализ A/B-теста

Тестовое задание для компании «Абсолют» по интернет-магазину. В задании требовалось приоритизировать гипотезы методами ICE и RICE, а затем сравнить метрики контрольной и тестовой групп.

В ноутбуке: подготовка данных, кумулятивные показатели, конверсия, средний чек и статистические проверки. В сохранённом анализе конверсия тестовой группы выше примерно на 18,9% (p ≈ 0,007); различие по среднему чеку статистически не подтверждено (p ≈ 0,788). Это результат данных тестового задания, а не эффект внедрения в реальном магазине.

[Открыть ноутбук](YP8_internet_store_project.ipynb). Для повторного расчёта нужны Python, pandas, NumPy, Matplotlib, seaborn, SciPy и исходные таблицы из задания. Перед бизнес-решением выводы нужно перепроверить на актуальных данных и с учётом дизайна эксперимента.
