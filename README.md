# Гипотезы и A/B-тест интернет-магазина

В этом учебном проекте я расставил девять идей маркетинга по приоритету с помощью ICE и RICE, а затем разобрал результаты августовского A/B-теста. В середине месяца у группы B резко выросла выручка. Я проверил, какую роль сыграл один крупный заказ и сохранилась ли разница после его исключения.

После сверки групп на 100 посетителей пришлось 2,90 заказа в B и 2,50 в A. Я предложил завершить тест в пользу B по частоте заказов. Убедительных оснований ожидать роста среднего чека не нашёл.
