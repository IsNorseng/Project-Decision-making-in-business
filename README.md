# Приоритизация гипотез и анализ A/B-теста

Учебный кейс по интернет-магазину: приоритизация гипотез методами ICE и RICE, затем сравнение метрик контрольной и тестовой групп.

В ноутбуке: подготовка данных, кумулятивные показатели, конверсия, средний чек и статистические проверки. В сохранённом анализе конверсия тестовой группы выше примерно на 18,9% (p ≈ 0,007); различие по среднему чеку статистически не подтверждено (p ≈ 0,788). Это результат учебного набора данных, а не эффект внедрения.

[Открыть ноутбук](YP8_internet_store_project.ipynb). Для повторного расчёта нужны Python, pandas, NumPy, Matplotlib, seaborn, SciPy и исходные таблицы из задания. Данные и условия эксперимента учебные; перед бизнес-решением выводы нужно перепроверить.
