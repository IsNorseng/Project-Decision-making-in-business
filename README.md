# Приоритизация решений и проверка гипотез

Учебный кейс по анализу данных интернет-магазина. Цель — сравнить продуктовые гипотезы, оценить их ожидаемый эффект и проверить результат A/B-теста.

## Задача

1. Подготовить данные по заказам и пользователям.
2. Приоритизировать гипотезы методами ICE и RICE.
3. Сравнить конверсию и средний чек в контрольной и тестовой группах.
4. Проверить статистическую значимость различий.

## Подход

В ноутбуке выполнены очистка и приведение типов, расчёт кумулятивных показателей, анализ выбросов и непараметрические проверки. В итоговой части отдельно рассматриваются конверсия и средний чек, чтобы не смешивать разные бизнес-метрики.

## Результаты

После очистки данных конверсия в тестовой группе выше примерно на 18,9%; различие по заказам на посетителя статистически значимо (p ≈ 0,007). Разница в среднем чеке статистически не подтверждена (p ≈ 0,788). Это вывод учебного анализа на предоставленном наборе данных, а не измеренный эффект внедрения.

## Запуск

Откройте [ноутбук проекта](Project%20Decision-making%20in%20business.ipynb) в Jupyter и выполните ячейки по порядку. Нужны Python, pandas, numpy, matplotlib, seaborn и scipy. Исходные таблицы должны быть доступны по путям, указанным в ноутбуке.

## Ограничения

Данные и экспериментальная среда учебные; причинный эффект изменения интерфейса или продукта не проверялся. Перед принятием решения нужны проверка рандомизации, длительности теста, мощности и устойчивости результата к альтернативным срезам.

**Инструменты:** Python, pandas, статистические тесты, ICE/RICE, A/B-тестирование.
